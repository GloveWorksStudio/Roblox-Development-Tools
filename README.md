# Roblox Daily Rewards & Quest System

An open-source Roblox Luau system for daily login rewards, player quests, and progression tracking.

## Features
- Daily login rewards with a 7-day cycle
- Daily quests for planting and harvesting
- Automatic daily resets using UTC time
- Server-side reward validation
- Player progress tracking
- Roblox Studio testing utilities

## Technologies
- Roblox Studio
- Luau
- Roblox RemoteFunctions
- Server-side gameplay systems

## Project Status
Work in progress. Additional dependencies, setup instructions, and examples are being prepared.

## Goal
Make reusable gameplay systems available to Roblox developers and help others learn how to build daily reward and quest mechanics.
